# 迁移到新电脑（极简版）

## 新电脑需要先有

**Python 3.9 或以上**：到 python.org 下载安装，安装时**勾选 "Add python.exe to PATH"**。

就这一样。不需要 Codex、不需要账号、不需要显卡。

## 三步完成

1. **复制文件夹**：把整个项目文件夹复制到新电脑，放哪都行。
   - `.venv`、`history` **不要复制**（`.venv` 和旧电脑的 Python 路径绑定，复制过去用不了）。
   - `models` 可以一起复制，省得重新下载 230 MB。
2. **运行安装**：在文件夹里打开命令行，运行下面这条命令。它会建环境、装依赖、下载模型（如果没复制）、启动程序，最后问你要不要开机自启，输入 `y` 回车。
   ```bash
   python setup.py
   ```
3. **测试**：打开记事本，单按**右 Alt**（屏幕下方出现红点和跳动的波形），说一句话，再按右 Alt，文字出现就成功了。

## 平时用到的文件（都是双击）

| 想做什么 | 双击这个 |
|---|---|
| 打开 | `start_sensevoice.cmd` |
| 关闭 | `stop_sensevoice.cmd` |
| 开机自启 | `install_autostart.cmd` |
| 取消开机自启 | `uninstall_autostart.cmd` |
| 改设置（快捷键、语言、历史条数…） | 用记事本打开 `config.py`，改完先双击关闭、再双击打开 |

## 出问题时

- 先看 `history\sensevoice.log` 的最后几行。正常运行时，最后一行应该是 `listening on Right Alt (SenseVoice)`。
- 日志里有 `microphone error`：打开 Windows 设置 → 隐私和安全性 → 麦克风，打开"允许桌面应用访问麦克风"。
- 项目文件夹换了位置：重新运行一次 `python setup.py`（或者至少重新双击 `install_autostart.cmd`）。
- 想了解原理或自己改代码：看 [项目说明.md](项目说明.md)。
